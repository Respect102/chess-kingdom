# Шахматное королевство

Шахматы с историей: дракон похитил принцессу, и путь к нему лежит через 10 глав. По дороге — уроки, задачи на мат, дебюты и босс в конце каждой главы.

**Играть:** https://respect102.github.io/chess-kingdom/

- 10 глав на карте, 10 боссов-персонажей с репликами
- 18 уроков с нуля, 150 задач на мат, справочник дебютов
- Подсказки лучшего хода с объяснением словами
- Звания, опыт, задания дня, достижения
- Музыка и звуки для каждой главы
- Версия для ПК и телефона, сказочный и строгий стиль, светлая и тёмная тема

Вся игра — один файл `index.html`, без сборки и внешних зависимостей.
